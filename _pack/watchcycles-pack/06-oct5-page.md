# The test: October 5, 2026

C3 high: Oct 6, 2025
Down-leg length used here: 364 days
Test date: **October 5, 2026**

This page exists so the claim cannot be quietly moved.

## The rule, written before the date

**If a major cycle low forms around this window, the 1,064 / 364 map still has a vote.**

**If Oct 5, 2026 passes with no major low, the old map is no longer the map.**

We will publish the result on this page the same day.

## What "major low" means here

Not a random red candle.
A cycle-scale low: a durable bottom in the same family as prior cycle troughs, not a one-day dip that immediately dies.

We will not pretend a −10% shake is C1 or C2.

## What the analog is (and is not)

Prior down-legs ended much deeper than C3 has traveled so far.
Any $29k–$37.9k style box on the site is only that memory. It is not an order and it is not required for the clock to "count."

The clock can be late on price and still be on time.
The clock can be on time and still be wrong.
